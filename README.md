# nathan-shumate.com

Personal site rebuilt with Nuxt 4, Vue 3, TypeScript, and Three.js.

## Development

```bash
pnpm install
pnpm dev
```

## Static build

```bash
pnpm generate
```

The generated static site is emitted to `.output/public` and can be deployed to Cloudflare Pages, Netlify, Vercel, or any static host.
