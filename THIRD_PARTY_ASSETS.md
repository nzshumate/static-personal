# Third-party assets

The eight-chapter journey is original procedural work: shader atmospheres, generated terrain, instanced vegetation, and small animated details.

## Libraries

| Library | License | Use |
| --- | --- | --- |
| [three](https://threejs.org/) | MIT | WebGL renderer, materials, post-processing |
| [nuxt](https://nuxt.com/) | MIT | App framework and static generation |
| [@nuxtjs/google-fonts](https://github.com/nuxt-modules/google-fonts) | MIT | Inter and Space Grotesk |

No third-party photographs or glTF models are used in the current visual system.
